# Sandbox Royale

Requires Node.js 22+, Docker Sandboxes (`sbx`), access to Claude, and an event pass.

```sh
git clone https://github.com/shelajev/sandbox-royale.git
cd sandbox-royale
./wizard.sh
```

Create your character. Complete Claude authentication if prompted, then enter your event pass in the browser when the game asks for it.
